# HTML MVC Starter (PM-01 / PM0204)

Starter template for the HTML Programmer practical module.

## Folder structure

- `index.html` — view (structure)
- `css/styles.css` — view (presentation)
- `js/app.js` — controller (behaviour)

## Setup in VS Code

1. Extract this folder.
2. Open the folder in VS Code.
3. Install the **Live Server** extension if you have not already.
4. Right-click `index.html` and choose **Open with Live Server**.
5. Click **Run controller action** to confirm JavaScript updates the page.
